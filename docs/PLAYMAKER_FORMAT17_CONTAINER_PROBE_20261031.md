# Unity 5.6 format-17 synthetic PlayMakerFSM: independent container probe

## Demonstrated result

GitHub Actions #266 (commit 42e2a7b8) passed all three jobs. In addition
to the unchanged base fixture, the new path generates a format-17 Unity
serialized file with a synthetic GameObject, Transform, **PlayMakerFSM-named**
MonoBehaviour and a separate MonoScript dependency.

The embedded 1,324-byte component is generated by the repository's existing
GUIBox/GUILabel synthetic ActionData serializer, then checked for its
GameObject ownership, script reference, optional null template pointer,
FSM name, action names, and byte-for-byte Python codec round-trip.

AssetsTools.NET 3.0.5, using the pinned classdata.tpk, independently
deserializes the built-in GameObject, Transform, MonoBehaviour **base** and
MonoScript fields, checks script-type and external dependency tables, and
extracts the MonoBehaviour byte range through the file's parsed object
descriptor. It rewrites the synthetic GameObject name with SetNewData,
writes both Unity files, and rereads the output. The component's original
SHA-256 must match the rewritten SHA-256. Python then reparses the output,
including GUIBox and GUILabel, and checks the exact ActionData and full
PlayMakerFSM bytes again.

## Historical editor/package availability and blocker

Official Unity lists [5.6.6f2](https://unity.com/es/releases/editor/whats-new/5.6.6f2),
released 2018-05-08, changeset 6bac21139588. Unity Hub's archive
[installation guidance](https://docs.unity.com/en-us/hub/add-editor)
provides a legitimate route for installing archived editors. The editor
is not installed or activated by this repository's CI.

Hutong Games' [PlayMaker 1.8.4 release notes](https://hutonggames.fogbugz.com/default.asp?ixWikiPage=1461&nRevision1=1&pg=pgWikiDiff)
explicitly list Unity 5.6 compatibility; the same notes list a fix for missing
iOS system events in Unity 5.6 in 1.8.5. These make 1.8.4/1.8.5 candidates for
the separate Editor experiment, but do not identify what The Forest shipped.
The current [PlayMaker 1 Asset Store listing](https://assetstore.unity.com/packages/tools/visual-scripting/playmaker-368)
shows version 1.9.12f1 with original Unity version 2022.3.62. That public
listing does not provide evidence that this version supports Unity 5.6.6f2.
Unity's [My Assets page](https://docs.unity.com/en-us/asset-store/downloads/organize-asset-packages)
lists packages owned by a Unity ID, but its public documentation does not
confirm that a specific archived PlayMaker 1.8.x release remains downloadable.

Hutong Games' [PlayMaker 2 installation guide](https://docs.hutonggames.com/welcome/installation/)
requires Unity 2022.3+ and explicitly rules out backward compatibility
with PlayMaker 1. The historical commercial PlayMaker 1 package is not
available as a licensed dependency in this repository or its CI environment.

Critical version evidence: a Hutong Games moderator stated that
[PlayMaker 1.7.8 kept reporting DLL version 1.7.7f6](https://hutonggames.com/playmakerforum/index.php?topic=9710.45).
Consequently neither the AOT strings 1.7.7.f6/1.7.7.6 nor
PlayMaker.dll AssemblyVersion 1.6.0.0 uniquely identify the installed
commercial release. Old Unity-targeted PlayMaker package variants also
existed, according to [Hutong Games support](https://hutonggames.com/playmakerforum/index.php?topic=19302.0).
A historical PlayMaker 1 package must be matched against actual serialized
fields, not chosen from these strings alone.

Hutong Games' own forum points purchasers with expired download links
to [info at hutonggames.com](https://hutonggames.com/playmakerforum/index.php?topic=7462.0)
for a refreshed legitimate download. A concrete next dependency action is
to request licensed PlayMaker 1.8.4 or 1.8.5 packages (or another release
confirmed compatible with Unity 5.6.6f2) and ask whether those older packages
remain available. Record the delivered package's exact version and assembly
metadata before using it. The versions in release notes remain candidates,
not evidence of The Forest's exact package.
Do not source a proprietary package from unlicensed mirrors or commit it.
